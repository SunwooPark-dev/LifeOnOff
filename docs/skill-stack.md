# 프로젝트용 스킬 스택 프리셋

이 프로젝트에서 우선적으로 사용할 Hermes 스킬과 권장 사용 시점입니다.

## 핵심 운영 스킬
- `writing-plans`: 기획안, 구현 계획, 실행 계획 작성
- `plan`: 코드/실행 전 상세 계획 문서 생성
- `subagent-driven-development`: 단계별 실행을 병렬/분업으로 추진할 때 사용

## 리서치/지식 축적 스킬
- `arxiv`: AI 관련 논문 탐색 및 근거 수집
- `llm-wiki`: 장기적으로 누적되는 지식베이스 구축
- `obsidian`: 노트형 지식 관리와 초안 연결
- `youtube-content`: 강연/인터뷰/세미나에서 자막 기반 인사이트 추출
- `ocr-and-documents`: PDF, 스캔 문서, 출판사 자료에서 텍스트 추출

## 집필/콘텐츠 제작 스킬
- `creative-ideation`: 책 콘셉트, 제목, 부제, 훅, 차별점 설계
- `powerpoint`: 강의안/제안서/출간 피치 자료 제작 시 사용
- `nano-pdf`: PDF 편집 및 교정본 수정 시 사용
- `google-workspace`: Docs/Sheets 기반 협업이 필요할 때 사용

## 확장 가능 스킬
- `notion`: 편집 캘린더, 장별 진행률 관리
- `himalaya`: 출판사/편집자 이메일 초안 및 커뮤니케이션
- `popular-web-designs`: 저자 사이트/랜딩페이지 구축 시 참고

## 권장 워크플로
1. `creative-ideation`으로 콘셉트와 독자 정의
2. `arxiv` + `youtube-content` + `ocr-and-documents`로 근거 수집
3. `llm-wiki` 또는 `obsidian`으로 지식 정리
4. `writing-plans`로 집필/편집/출간 계획 수립
5. 챕터별 초안 작성 및 검토
6. `google-workspace` 또는 `powerpoint`로 외부 공유본 제작
7. `nano-pdf`로 교정 단계 대응

## 이 프로젝트에서 바로 사용할 기본 조합
- 기획: `creative-ideation`, `writing-plans`
- 리서치: `arxiv`, `youtube-content`, `obsidian`
- 장기 축적: `llm-wiki`
- 실행: `subagent-driven-development`

주의:
- 실제 스킬은 Hermes 런타임에서 호출해 사용합니다.
- 이 문서는 프로젝트용 추천 프리셋이며, 필요에 따라 계속 업데이트합니다.
