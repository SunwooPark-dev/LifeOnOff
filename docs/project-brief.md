# AI 관련 서적 출판 프로젝트 브리프

## 1. 프로젝트 목표
AI 관련 서적을 기획하고, 근거 기반의 원고를 작성하며, 출판 가능한 수준의 구조화된 원고 패키지까지 만드는 것.

## 2. 현재 전제
- 새 프로젝트 폴더에서 시작
- 주제는 "AI 관련 서적 출판"
- 아직 세부 독자층, 책의 포지셔닝, 챕터 구조는 미확정
- 지금 단계의 최우선 과제는 좋은 기획안과 실행 구조를 만드는 것

## 3. 권장 최종 산출물
- 책 한 줄 콘셉트
- 목표 독자 정의
- 경쟁서 분석
- 차별점 정의
- 가제/부제 후보
- 상세 목차
- 챕터별 핵심 메시지
- 근거 자료 저장소
- 샘플 원고 1~2개 챕터
- 출판 제안용 요약 문서

## 4. 추천 전략
### 전략 A: 입문자 대중서
- 폭넓은 독자층 확보 가능
- 출판 시장 접근성이 높음
- 단, 차별화가 어려움

### 전략 B: 실무자용 AI 활용서
- 뚜렷한 독자층 확보 가능
- 사례/워크플로 중심으로 경쟁력 확보 가능
- 단, 빠른 기술 변화 반영 필요

### 전략 C: AI 시대의 사고법/전략서
- 장기적으로 덜 낡을 수 있음
- 저자 브랜딩에 유리
- 단, 주장과 구조가 강해야 함

현재 기본 추천: 전략 B + C 혼합형
- 실무 활용성을 주축으로 하되
- 단순 툴 사용법이 아니라 사고법, 워크플로, 조직/개인 생산성 관점까지 포함

## 5. 초기에 반드시 확정할 항목
1. 핵심 독자 1명 정의
2. 이 책이 해결할 가장 큰 문제 1개 정의
3. 독자가 책을 덮은 뒤 할 수 있어야 하는 일 3개 정의
4. 기존 유사서와의 차별점 3개 정의
5. 저자의 고유 경험/시각 3개 정의

## 6. 추천 폴더 운영 원칙
- `research/`에는 출처 중심 자료 저장
- `manuscript/`에는 목차와 챕터 초안 저장
- `docs/`에는 전략, 기획, 운영 문서 저장
- 수정 이력은 git으로 관리
